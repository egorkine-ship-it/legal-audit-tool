# Правила использования LLM

Цель: экономить токены и снижать риск галлюцинаций. Система сначала собирает и
оценивает факты детерминированно, а LLM подключается только там, где нужна
семантическая проверка текста или аккуратная редактура.

## Режимы проверки

- `quick` / **Быстрое КП** — режим по умолчанию. LLM не вызывается вообще:
  документный чек-лист, PD-находки, короткое КП и ZIP массовой проверки строятся
  из детерминированно собранных фактов.
- `deep` / **Глубокий аудит** — осознанно дорогой режим. Включает LLM-анализ
  документов по чек-листам, агентную перепроверку для одиночной проверки и
  полный внутренний PDF. Этот режим используется, когда нужен рабочий материал
  для юриста, а не первичное коммерческое касание.

## Проверяется без LLM

- URL, редиректы, HTTP-статусы, HTTPS, mixed content.
- Поиск публичных страниц, footer/header-ссылок, sitemap/robots.
- Наличие и доступность документов: HTML, PDF, DOCX.
- Извлечение текста из документов без OCR.
- Формы, поля, категории данных, checkbox, prechecked, текст рядом с формой.
- Cookie-баннер, cookies до согласия, network requests, script/iframe src.
- Трекеры и сторонние сервисы по `data/tracker_domains.yml`.
- Простые признаки в документах: ИНН, ОГРН, email, даты, плейсхолдеры,
  ключевые слова про цели, сроки, отзыв согласия, cookies, третьих лиц,
  трансграничную передачу.
- Правила `R001..R027`, ядро-чеклист и компактные PD-находки для КП.
- Генерация короткого клиентского PDF-КП из уже собранных фактов.

## Проверяется LLM, но только по ограниченному входу

- Семантическая полнота документа по чек-листу, когда эвристик недостаточно.
- Неоднозначные формулировки: слишком общие цели, третьи лица без конкретики,
  конфликт между текстом политики и обнаруженными сервисами.
- Агентная перепроверка сайта, когда ключевые документы не найдены обычным
  сбором: агент может открыть страницы того же домена, но найденные URL всё
  равно повторно скачиваются и валидируются кодом.
- Редактура резюме, КП и письма: LLM получает только компактный fact bundle,
  без полного текста документов, HTML и raw JSON.

## Не утверждается автоматически

- Факт нарушения закона.
- Реальное место хранения баз данных.
- Наличие/актуальность уведомления Роскомнадзора без надёжной проверки реестра.
- Содержание CRM, CMS, серверной логики, договоров с обработчиками,
  внутренних актов и журналов согласий.
- Окончательная сумма ответственности.

## Правила для промптов

- Не передавать в LLM полный сайт или все документы целиком для клиентского КП.
- Для анализа документа передавать ограниченный фрагмент текста и чек-лист.
- Для КП/письма передавать только `build_fact_bundle`: top-находки, документы,
  формы, трекеры, короткие доказательства и настройки бюро.
- Не разрешать LLM ставить `found` без цитаты из документа.
- Любой вывод LLM считать справочным и подтверждать детерминированными фактами.
