# Экспресс-аудит публичной части сайтов · признаки рисков по 152-ФЗ

Локальный внутренний инструмент юридического бюро для автоматизированного
**экспресс-анализа публичной части сайтов** на признаки возможных рисков и
несоответствий требованиям законодательства РФ о персональных данных (152-ФЗ),
а также смежных рисков по cookie, рекламным рассылкам, публичным документам,
сторонним сервисам и трансграничной передаче.

> ⚠️ **Важно.** Приложение анализирует только **публично доступные** страницы и
> формирует **предварительные выводы** («признаки риска»), а не окончательную
> квалификацию нарушения. Автоматическая проверка **не заменяет** полноценный
> юридический аудит. **Любой отчёт, коммерческое предложение и письмо перед
> отправкой клиенту должен проверить юрист.**

---

## Возможности

- Проверка одного сайта или массовая загрузка списка (CSV/XLSX).
- Обход публичных страниц (по умолчанию до 20) через Playwright с фолбэком на HTTP.
- Поиск и классификация форм сбора персональных данных и механики согласий.
- Поиск и разбор документов: политика ПДн, согласия, cookie policy, оферта,
  пользовательское соглашение (HTML/PDF/DOCX).
- Анализ документов по строгим чек-листам (эвристика + опционально LLM).
- Проверка cookie-баннера, cookies/запросов до согласия, трекеров и сторонних сервисов.
- Технические проверки: HTTPS, mixed content, внешние домены, IP/страна (опционально).
- Rule engine + подсчёт risk score / уровня риска / confidence.
- Генерация PDF-отчёта, текста коммерческого предложения и письма для первичного контакта.
- Локальная база (SQLite), история проверок и статусы лидов.

## 1. Установка

Требуется **Python 3.11+** (проект также запускается на 3.9, но рекомендуется 3.11+).

```bash
# 1. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt
```

### Playwright browsers

Playwright используется для рендеринга страниц и открытия модальных форм:

```bash
python -m playwright install chromium
```

Если Playwright недоступен, сканер автоматически переключается на упрощённый
HTTP-режим (без JS-рендеринга и модальных форм).

### WeasyPrint (PDF)

PDF по умолчанию генерируется через **WeasyPrint**. Он требует системных
библиотек (pango, cairo, gdk-pixbuf).

- macOS: `brew install pango gdk-pixbuf libffi`
- Debian/Ubuntu: `sudo apt install libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libffi-dev`

Если поставить WeasyPrint не удаётся — **ничего настраивать не нужно**: приложение
автоматически формирует PDF через Playwright. Если недоступно и это — сохраняется
HTML-версия отчёта рядом с ожидаемым PDF.

## 2. Запуск

```bash
streamlit run app.py
```

Откроется локальный веб-интерфейс с пятью вкладками:

1. **Проверка одного сайта** — ввод URL, отрасли, параметров, запуск и просмотр результата.
2. **Массовая проверка** — загрузка CSV/XLSX, прогресс, итоговая таблица, экспорт XLSX и ZIP с PDF.
3. **История** — таблица проверок, смена статуса лида, скачивание PDF.
4. **Подробности проверки** — полная детализация по выбранному `scan_id`.
5. **Настройки** — LLM, параметры сканирования, реквизиты бюро, цены услуг.

## 3. Настройка LLM API key

LLM используется для анализа документов по чек-листу и генерации юридического текста
(с фолбэком на шаблоны, если LLM выключена/недоступна).

Два способа:

- **Через интерфейс:** вкладка «Настройки» → поля *LLM API key / base URL / model* →
  «Сохранить». Значения хранятся локально в `data/app_settings.json`.
- **Через `.env`:** скопируйте `.env.example` в `.env` и заполните:

  ```env
  LLM_API_KEY=sk-...
  LLM_BASE_URL=https://api.openai.com/v1
  LLM_MODEL=gpt-4o-mini
  ENABLE_LLM=1
  ```

Поддерживается любой **OpenAI-совместимый** endpoint (поле `LLM_BASE_URL`).
Ответы LLM по чек-листу всегда строго структурированы (JSON); статус `found`
не выставляется без цитаты из документа.

## 4. Массовая проверка (CSV/XLSX)

Файл со столбцами (обязателен только `site_url`):

| company_name | site_url | industry | email | comment |
|--------------|----------|----------|-------|---------|
| ООО Пример   | example.ru | услуги | info@example.ru | лид с выставки |

`industry` — одно из: `auto, медицина, образование, IT/SaaS, e-commerce, услуги,
финансы, HR/рекрутинг, недвижимость, туризм, другое` (иначе используется `auto`).

Загрузите файл во вкладке «Массовая проверка», проверьте предпросмотр и запустите.
По завершении доступны экспорт результатов в **XLSX** и архив всех **PDF** в **ZIP**.

## 5. Добавление правил (rule engine)

Правила и их формулировки редактируются в [`data/legal_rules.yml`](data/legal_rules.yml)
**без изменения кода**:

- изменить текст/вес/уровень — правьте `title`, `report_phrase`, `score`, `risk_level`;
- отключить правило — `enabled: false`;
- **новое правило** — добавьте предикат в `PREDICATES` в
  [`legal/rule_engine.py`](legal/rule_engine.py) с новым `id` и добавьте элемент с тем же
  `id` в YAML.

Чек-листы документов редактируются в
[`data/document_checklists.yml`](data/document_checklists.yml): новый пункт с `keywords`,
`risk_if_missing` и `applies_when` начинает проверяться эвристикой и уходит в LLM
автоматически.

## 6. Добавление трекеров

Каталог сторонних сервисов — [`data/tracker_domains.yml`](data/tracker_domains.yml).
Добавьте элемент в `providers`:

```yaml
  - provider_name: "Новый сервис"
    category: analytics        # analytics|marketing|chat|crm|calltracking|payment|delivery|cdn|other
    country_hint: RU           # RU|foreign|unknown
    legal_risk: medium         # low|medium|high
    should_be_disclosed_in_policy: true
    should_trigger_cookie_check: true
    should_trigger_cross_border_check: false
    domains: ["example-tracker.com"]
    patterns: ["exTrack("]     # подстроки для inline-JS/HTML
```

Известные трекинг-cookie перечислены в разделе `tracking_cookie_names` того же файла.

## 7. Ограничения автоматической проверки

Автоматическая проверка видит **только публичную часть сайта** и **не имеет доступа** к:

- CRM; CMS/admin panel; базе данных; серверной логике;
- договорам с обработчиками; внутренним локальным актам; журналам согласий;
- уведомлениям РКН (если оператор не идентифицирован);
- фактическому месту хранения базы; процессам удаления/уточнения ПДн;
- переписке с субъектами ПДн.

Поэтому **все итоговые выводы — только «признаки риска»**, а не окончательная
квалификация нарушения. GeoIP-страна сервера без локальной базы GeoLite2 не
определяется (`unknown`). OCR для сканов PDF в этой версии не используется — такие
документы помечаются как требующие ручной проверки.

**Правила сканирования:** проверяются только публичные страницы; авторизация и CAPTCHA
не обходятся; формы **не отправляются**, submit-кнопки не нажимаются; нагрузочное
тестирование и пентест не выполняются; соблюдаются лимит страниц и задержки; используется
идентифицирующий user-agent `NexoraLegalInternalComplianceScanner/1.0`.

## 8. Проверка отчёта юристом

Перед отправкой клиенту **обязательно**:

- проверьте корректность выявленных признаков риска и формулировок;
- подтвердите юридические выводы (автоматические выводы предварительны);
- уточните реквизиты, цены и состав услуг в коммерческом предложении;
- отправляйте письмо и КП **вручную** — приложение только формирует тексты, но
  ничего не отправляет.

## 9. Структура проекта

```
app.py                    Streamlit-интерфейс (5 вкладок)
config/settings.py        Конфигурация (env + app_settings.json)
data/*.yml                Правила, трекеры, чек-листы, пакеты услуг (редактируемые)
scanner/                  Сканирование: браузер, краулер, детекторы форм/cookie/трекеров, документы
legal/                    Rule engine, scoring, анализ документов и чек-листов
llm/                      LLM-клиент, промпты, ремонт JSON
reports/                  Генерация HTML/PDF-отчёта
database/                 SQLite: схема и репозитории
tests/                    Базовые тесты
exports/pdf/              Готовые PDF-отчёты
```

## Дисклеймер

Инструмент предназначен для внутреннего использования юридическим бюро при первичной
оценке. Он не является юридической консультацией и не устанавливает факта нарушения
законодательства. Итоговую правовую оценку даёт юрист.
